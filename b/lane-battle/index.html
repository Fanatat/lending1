Lane Battle

Прототип, который проверяет ровно один вопрос: кайфово ли это.

Кадр-доказательство

Двадцатисекундный автобой прямо в странице, Canvas 2D, юниты — прямоугольники без арта. Игрок только спавнит юнитов на накопленную еду, бой идёт сам. Сбоку — живые слайдеры баланса (урон, HP, скорость, экономика): крутишь — меняется текущий бой, без перезапуска. Кнопка «сброс к балансу автора» возвращает исходные значения. Бой детерминирован: тот же сид и те же параметры дают тот же результат — сид показан и меняется кнопкой, есть кнопка «повторить бой».

Разрез
  • Автобой-симуляция
  • Юниты по накопленной еде
  • balance.json (живой тюнинг)
  • Ветка prototype/battle
Цена решения

Почему прототип сознательно урезан до неприличия — без меты, без сохранений, без SDK площадок, без звука и финального арта. Потому что если ядро боя не «кайфовое» на голых прямоугольниках, никакая мета его не спасёт, а вложенные в мету три недели будут потрачены впустую.

Trade-off: прототип нельзя показать инвестору или площадке — он выглядит нищим. Он и не для них.
