AI Animation OS

Конвейер, который делает образовательный ролик от темы до MP4. На трёх языках.

Кадр-доказательство

Одиннадцать узлов пайплайна в цепь: Script → Episode → Scene → Entities → Environments → Shot → Prompt → Image → Audio → Timeline → Export. Клик или Enter по узлу раскрывает артефакт этого шага — JSON сценария, Pydantic-модель, промпт, кадр, форму звуковой волны. Материалы от автора ещё не переданы, поэтому каждый артефакт сейчас — честно помеченная заглушка, а не выдумка под видом настоящего. Переключатель EN/ES/RU меняет текст промпта, подпись кадра и голос — изображение остаётся тем же DOM-элементом, не перерисовывается. Отдельно — честная заглушка изображения с подписью «инфраструктура готова, качество контента впереди».

Разрез
  • Markdown: производственные знания
  • Python: оркестрация
  • Pydantic: валидация LLM-вывода
  • generate once, reuse many — кэш
  • FFmpeg: экспорт MP4
Цена решения

Почему ответ LLM считается недоверенным вводом: Prompt → LLM → очистка → парсинг JSON → валидация Pydantic → артефакт. Любой шаг, доверяющий модели напрямую, ломает пайплайн через раз и делает воспроизводимость невозможной.

Заплачено объёмом кода валидации и тем, что модель периодически не может пройти собственный контракт. Куплено то, что 18+ MP4-файлов по 6 проектам на 3 языках собираются повторяемо. Второе решение того же ряда: «Python управляет, Markdown знает» — оркестрация в коде, производственные знания в текстовых файлах. И третье: generate once, reuse many — перед генерацией всегда поиск в библиотеке и кэше.
